**借入返済管理**は、住宅ローン・カードローン・リボなど、**複数の借入を一か所で見たい人**向けの無料iOSアプリです。手入力中心で、残高・毎月返済・予定日を残します。家計簿の「支出」とは別枠の、**返済だけ**のメモです。

まだ分かっていないこと: 銀行連携はないので、**契約書・マイページの数字が正**です。アプリは入力どおりの目安に過ぎません。

## できること

- 借入の登録、現在残高、毎月返済額
- 返済予定日と返済実績
- 月別の返済サマリー
- ホームで総残高・今月の予定の目安
- 返済日前の通知（OS設定に依存）
- JSON / CSV バックアップ

方針: アカウント登録なし、データは端末内。開発者サーバーへ借入内容を送る機能はない（ストア説明に準拠）。

## 使うときの前提（ここが本体）

**手入力が前提**です。口座や契約からの自動同期はありません。返済後に残高を直す手間は自分持ちです。その代わりクラウド同期やアカウント作成を避けています。

画面上の完済見込み・残高は、**入力に基づく目安**です。繰上・ボーナス払い・金利改定・手数料などで契約が動くと、アプリだけ古い数字になります。金融機関側を正にしてください。

家計簿との分担: 家計簿は「今月どこに使ったか」、こちらは「あと何件・今月いくら返すか」。食費までここに入れる用途ではありません。

通知は補助です。集中モードで届かないことがあります。約定返済は口座振替や銀行アプリ側のリマインドも併用してください。

入力の最低セットは、借入ごとに **次回返済日・毎回の返済額・いまの残高** の3点です。金利や残期間まで全部入れようとして止まると、一覧の価値が落ちます。

端末変更前は JSON / CSV バックアップを取ってください。端末内保存なので、紛失・初期化のリスクは自分で握ります。

## 向いている人／向いていない人

向いている例:

- 借入が複数で、総残高と今月の返済を一目で揃えたい
- 家計簿は続けているが、返済スケジュールだけ別画面が欲しい
- 外部に上げず、端末内だけで把握したい

向いていない例:

- 繰上順の最適計算やリファイナンス相談の代替
- 税務・債務整理の判断や提出資料の代替
- 銀行ログイン連携での自動更新

目安: 返済日に残高を1〜2分で直せるか。負担なら件数を減らすか、公式画面だけで足りるか検討してください。

困窮が近い・督促が来ているときは、アプリより契約先や公的な相談窓口を優先してください。金融・法律の助言はしません。無料のため広告が出ることがあります。
