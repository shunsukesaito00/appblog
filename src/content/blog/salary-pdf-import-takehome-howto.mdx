会社員の給与は、毎月 **総支給** と **手取り** がセットで届きます。紙や PDF のままだと、過去の明細を探すのが面倒で、「去年の今ごろいくらだったか」をすぐに答えられない——そんな経験はありませんか。

この記事では、**給与明細 PDF をスマホに取り込み、手取りを記録して推移を見る** ための実務的な考え方をまとめます。個人開発の iOS アプリ **[給与明細管理](/blog/app-intro-salary)** を例に説明しますが、**明細管理の一般論** として読んでもらえます。

## この記事で分かること

- **手取りを毎月記録する理由**（総支給だけでは足りない点）
- **PDF 取り込みの注意点**（うまくいかないときの典型）
- **向いている人 / 向いていない人**
- スマホアプリで明細を残すときの **セキュリティの考え方**
- iOS アプリでの **具体的な取り込み手順のイメージ**

## なぜ「手取り」を記録するのか

給与明細でまず目がいくのは **総支給** かもしれません。でも家計やライフプランで使えるのは、控除を引いたあとの **手取り** です。

手取りを月ごとに残しておくと、次のような判断がしやすくなります。

- **昇給・降給・社会保険料の変更** で、実際の生活費に効いているか
- **賞与** が入った月と通常月の差
- **転職や副業** を検討するときの、直近の収入の流れ
- 住宅ローンや家賃の見直しの **ざっくりした目安**

総支給だけメモしていると、「額面は上がったのに手取りが増えていない」ことに気づくのが遅れます。**手取りの推移** を見るのは、派手な家計術ではなく、ごく地味で実用的な習慣です。

## 給与明細 PDF 取り込みの注意点

多くの会社は、給与明細を **PDF** や Web 明細で配布しています。スマホアプリに取り込むとき、次の点に注意してください。

### 1. 会社・給与ソフトごとにレイアウトが違う

表の並び、項目名、賞与の扱いは会社によって異なります。PDF から自動で読み取る場合、**一部の項目が空欄になる・ずれる** ことがあります。取り込み後に **総支給・手取り・控除の代表項目** を目視で確認する習慣をつけてください。

### 2. パスワード付き PDF がある

セキュリティのため、PDF にパスワードがかかっているケースがあります。アプリや OS の仕様によっては、**解除後に取り込む** 必要があります。社内ポータルの案内に従ってください。

### 3. スキャン画像は読み取り精度が落ちることがある

カメラで撮った明細は、影や解像度の影響で **数字の誤認識** が起きやすいです。可能なら **元の PDF ファイル** からの取り込みを優先するのがおすすめです。

### 4. 個人情報が含まれる

氏名、社員番号、口座情報、控除の内訳など、**機微な情報** が PDF に含まれます。アプリを選ぶときは、「データを外部サーバーに送らないか」「端末内で暗号化するか」を確認してください。

### 5. 取り込み ≠ 確定申告・年末調整の代わりではない

アプリに記録した数字は、あくまで **自分用のメモ・見通し** です。税金や控除の正式な判断は、会社の人事・税理士・国税庁の情報などで行ってください。

## こんな人向け

- 毎月の **手取りの変化** をグラフで見たい
- 紙やメールの PDF が散らばっていて、**過去の明細を探しにくい**
- 転職・昇給・賞与のタイミングで **収入の流れを振り返りたい**
- 家計簿までは本格運用しないが、**収入だけは残したい**

## 向いていないケース

- 会社指定の勤怠・給与システムだけで完結させたい（社内ルールで外部保存が禁止されている場合）
- 確定申告の計算をアプリだけで完結させたい
- 複数人分の給与を一括で法人管理したい（個人向けアプリの想定外）

## iOSアプリでの取り込みの流れ（給与明細管理の例）

個人開発の **[給与明細管理](/blog/app-intro-salary)** では、おおよど次の方法で登録できます。

1. **PDF ファイル** を共有シートからアプリに渡す  
2. **写真・カメラ** で明細を撮影して取り込む  
3. うまく読み取れない場合は **手入力** で補正する  

取り込み後は、**月別の手取り推移** や **総支給推移** をグラフで確認できます。賞与を含めた見込み年収の参考表示など、年単位の見通しもアプリ内で扱えます。

データは **端末内に AES-256 で暗号化保存** し、**外部サーバーへ送信しない** 方針です（詳細は [アプリ紹介記事](/blog/app-intro-salary) の「データの扱い」を参照）。

## 毎月のルーティン例

無理のない運用例です。

| タイミング | やること |
| --- | --- |
| 給与日〜翌週 | PDF を保存し、アプリに取り込む |
| 取り込み直後 | 総支給・手取りが妥当か **1分だけ目視確認** |
| 四半期に1回 | 手取りグラフを見て、控除や手当の変化に気づく |
| 賞与の月 | 通常月と分けて記録し、年収見通しを更新 |

「完璧に全項目を入れる」より、**手取りと総支給を毎月欠かさない** 方が、長く続きやすいです。

## よくある質問

### PDF が読み取れないときは？

まず **元 PDF** で再試行し、ダメなら **手入力** でその月だけ登録します。1か月分の欠損より、続けることの方が価値が大きいです。

### 手取りと振込額が一致しないことがあるのはなぜ？

会社貸与の控除、社内積立、翌月調整など、**明細と振込のタイミングがずれる** 場合があります。明細は「給与の計算結果」、口座は「実際の入金」として、両方メモしておくと混乱が減ります。

### 紙の明細しかない場合は？

カメラ取り込みか手入力です。撮影時は **影が入らない・数字がはっきり見える** よう平面に置いてください。

### 無料アプリで足りる？

収入の記録と推移の確認が目的なら、無料アプリでも十分なことが多いです。広告の有無やバックアップの扱いは、アプリごとにストア説明を確認してください。
