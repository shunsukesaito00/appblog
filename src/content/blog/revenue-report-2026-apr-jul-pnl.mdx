**2026年4月〜7月**の個人開発について、「収益だけ」ではなく **出費も載せた損益** をまとめます。金額は **日本円を主表記** とし、元の USD も併記します。

結論から言うと、この4ヶ月の **AdMob 推定収益は合計 約921円（$5.81）**、一方で Cursor Pro+ と Apple Developer だけで **約4.3万円（按分）〜約5.4万円（年会費全額載せ）** です。**利益は出ていません**。

**為替:** 1USD = **158.54円**（2026年8月1日時点・[open.er-api](https://open.er-api.com/v6/latest/USD)。8月2日は市場休日のため直近レートを使用）。円は四捨五入。

## この記事で分かること

- 4〜7月の **AdMob 月次収益の合計**（既存の月次記事の合算）
- 同期間の **主な固定費**（Cursor Pro+・Apple Developer Program）
- **期間按分**と **年会費を現金で全額載せた場合** の2通りの損益（円建て）
- 数字の前提・含まれないコスト

**対象期間:** 2026年4月1日〜2026年7月31日  
**収益の根拠:** 公開済みの月次収益報告（AdMob 推定収益）  
**出費の根拠:** Cursor Pro+ **$60/月×4**、Apple Developer **$99/年**（運営確認済みの額）

## 前提と注意（先に読む）

| 項目 | 扱い |
| --- | --- |
| AdMob | **推定収益**。確定入金・税務上の所得ではない |
| Cursor Pro+ | **$60/月** × 4ヶ月（4〜7月） |

「黒字化できているか」の判断材料であって、**確定申告用の帳簿ではありません**。

## 正直な所感

- **AdMob の月次ログは続ける価値がある**（小さくても推移が分かる）。一方で **損益を見ないと「続いている感」だけが残る**
- Cursor はサイト・記事・アプリ作業の生産性に使っているので、「無駄」とは思っていない。ただ **個人開発の広告収益では全くペイしない** のも事実
- Apple の年会費はストア公開の入場料。按分でも無視できない固定費
- この数字を見て「すぐやめる／すぐ伸ばす」ではなく、**検証段階のコスト構造**として記録しておく

次の四半期（8〜10月など）も、同じ切り口で収益と固定費を円建てで並べられるようにします。

## Keep / Problem / Try

- **Keep:** 月次の AdMob 記録。給与明細を軸にしたポートフォリオ前提
- **Problem:** 収益（千円未満）と固定費（数万円）のスケール差。6〜7月の更新停滞
- **Try:**
  1. 8月以降も **月次収益** を止めない
  2. 次の損益まとめも **円建て＋為替日付** を残す
  3. アプリ側は大きな逆転を狙わず、**止めない更新**（Connect の説明文編集は対象外）

## よくある質問

### 個人開発はツール代を含めると赤字ですか？

規模と契約プラン次第です。このログでは、**AdMob 推定 約921円** に対し Cursor Pro+ と Apple 年会費（按分）だけで **約4.3万円** なので、この期間・この前提では **赤字** です。

### 円の金額は確定の収支ですか？

いいえ。AdMob は **推定収益**、出費の USD は確認済みでも、円は **記事作成時点の為替による換算** です。実際のカード決済レート・入金レートとは異なります。

### Apple Developer の年会費を4ヶ月にどう載せるべきですか？

会計の流儀によります。本記事では **期間按分（約5,232円）** を主、**更新月に全額（約15,695円）** を併記しました。確定申告の扱いとは別問題です。

### AdMob の金額は確定収入ですか？

いいえ。**推定収益**です。入金額・税務上の所得とは一致しない場合があります。
